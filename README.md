# 🏗️ IdeaVerse 1000

**1000 Project Ideas Across Every Field** — from school to PhD level.

## 🚀 Setup Instructions

This project is a Next.js 14 PWA built with TypeScript, Tailwind CSS, and shadcn/ui.

### Step 1: Scaffolding
See `SETUP_STEP_1.md` for complete Next.js 14 + Core Dependencies setup.

### Quick Start (after scaffolding)
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
